# HF三部曲 & 魔法使いの夜 票房追踪 / 興行収入トラッカー / Box Office Tracker

**中文**：用 [mimorin2014.com](https://mimorin2014.com/) 的每日合算售票样本，按官方公布的动员/票房节点换算，估算并追踪 Fate/stay night [Heaven's Feel] 三部曲与《魔法使いの夜》的票房，并按 HF 三部的走势预测《魔法使いの夜》的最终票房。每天自动更新。

**日本語**：[mimorin2014.com](https://mimorin2014.com/) の日別合算販売数サンプルを公式発表の動員・興収に合わせて換算し、劇場版「Fate/stay night [Heaven's Feel]」三部作と『魔法使いの夜』の興行収入を推計・追跡します。HF三部作の推移から『魔法使いの夜』の最終興収も予測します。毎日自動更新。

**English**: Estimates and tracks the box office of the Fate/stay night [Heaven's Feel] trilogy and *Witch on the Holy Night* by converting daily ticket-sale samples from [mimorin2014.com](https://mimorin2014.com/) using official admissions and gross figures, and projects the latter's final gross from the HF trilogy's runs. Updated daily.

- `data/sample.csv`：每日样本 / 日別サンプル / daily samples
- `data/milestones.csv`：官方节点及来源 / 公式発表と出典 / official figures and sources
- `index.html`：页面（中文 / 日本語 / English，可用 `?lang=zh|ja|en` 指定）

非官方的个人统计页面，数字为估算，仅供参考。 / 非公式の個人集計ページです。 / Unofficial personal tracker; figures are estimates.
