# HF三部曲 & 魔法使いの夜 票房追踪

用 [mimorin2014.com](https://mimorin2014.com/) 每日「デイリー合算ランキング（19時中間集計）」的售票样本，按官方公布的动员/票房节点换算，估算并追踪 Fate/stay night [Heaven's Feel] 三部曲与《魔法使いの夜》的票房，并按 HF 三部的走势预测《魔法使いの夜》的最终票房。

- `data/sample.csv`：每日 19 时样本（每天自动追加）
- `data/milestones.csv`：官方动员与票房节点及来源
- `index.html`：页面，所有估算和预测都在浏览器里根据上面两个文件实时计算

非官方的个人统计页面，数字为估算，仅供参考。
